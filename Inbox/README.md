# Inbox

Сюда складываются новые и необработанные материалы.

## Можно помещать

- заметки;
- документы;
- выдержки из переписки;
- результаты встреч;
- идеи;
- ошибки;
- вопросы.

## Нельзя

- хранить секреты;
- считать материал проверенным;
- использовать Inbox как источник истины;
- бездумно переносить всё в постоянные разделы.

Каждый материал должен быть обработан, связан с источником и перемещён
в подходящий раздел или оставлен с понятной причиной.
