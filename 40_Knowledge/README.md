# Раздел Knowledge

Здесь хранятся обобщённые знания, которые используются в нескольких
проектах или задачах.

## Хорошая заметка

- отвечает на один вопрос;
- начинается с краткого вывода;
- содержит определения и ограничения;
- показывает источник;
- отделяет факт от интерпретации;
- имеет ссылки на связанные темы;
- не дублирует исходную документацию.

## Рабочий цикл

1. Найти материал в `Inbox/`.
2. Проверить источник.
3. Сформулировать тезис.
4. Добавить детали и ограничения.
5. Связать с контекстом и решениями.
6. Проверить, что заметка пригодна для передачи агенту.
