# Универсальные skills

Эти skills являются portable playbooks. Они не зависят от интерфейса
или поставщика модели.

## Skills

- `capture-knowledge.md` - сохранить новый факт, решение или урок;
- `ba-intake.md` - ограничить задачу и сформулировать проблему;
- `ba-discovery.md` - подготовить discovery и работу со stakeholder;
- `ba-requirements.md` - создать и проверить требования;
- `ba-review.md` - найти gaps, конфликты и edge cases;
- `ba-traceability.md` - проверить связи между артефактами;
- `ba-decision.md` - сравнить варианты и оформить решение;
- `ba-delivery-readiness.md` - проверить готовность к реализации;
- `ba-outcome-review.md` - сопоставить результат с целью.

## Использование

Передай агенту путь к нужному Markdown-файлу и связанные заметки.
Если платформа поддерживает slash commands, можно сделать локальный alias.
Сам skill не зависит от наличия такого alias.
