# BA decision

Compare options by value, effort, risk, dependencies, reversibility,
time to learn, and impact.

State criteria before ranking. Return context, options, evidence, selected
option or unresolved choice, trade-offs, consequences, owner, and review
conditions.

Read `80_BA-Harness/07_Decision_and_Prioritization.md`.
The agent structures the decision; the decision owner approves it.
