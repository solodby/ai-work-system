# BA delivery readiness

Check goal, scope, value, requirements, acceptance criteria, edge cases,
dependencies, non-functional needs, risks, open questions, and change impact.

Return ready items, blockers, missing evidence, stakeholder questions,
required corrections, and residual risks.

Read `80_BA-Harness/08_Delivery_Readiness.md`.
Do not mark work ready while critical assumptions are hidden.
