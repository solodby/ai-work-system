# Capture knowledge

Use after a substantial task, decision, error, or process change.

1. Read related context, process, decision, and incident notes.
2. Search for an existing note on the same topic.
3. Separate facts, assumptions, and open questions.
4. Check source and date.
5. Update an existing note when possible.
6. Create a new note only when the information is reusable.
7. Add confidence, verification, source, and WikiLinks.
8. Record prevention for every failure.

For an error capture symptom, impact, timeline, evidence, cause confidence,
fix, verification, prevention, and open questions.

Do not store secrets, personal data, raw credentials, or unnecessary transcripts.
