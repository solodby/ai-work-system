# BA traceability

Check the chain:

```text
Goal -> Requirement -> Decision -> Story -> Acceptance -> Test -> Outcome
```

Find orphan requirements, missing sources, duplicate items, broken links,
unreviewed changes, and impacted artifacts.

Return missing links and evidence.
Do not claim traceability when source, approval, test, or outcome is absent.

Read `80_BA-Harness/06_Traceability.md`.
