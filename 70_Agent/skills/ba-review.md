# BA review

Review analysis and requirements before approval or delivery.

Find ambiguous terms, missing actors, conflicts, missing normal and negative
flows, boundary cases, untestable criteria, unsupported assumptions,
dependencies, compliance gaps, and missing evidence.

Return each finding with severity, evidence, affected item, and a question or
correction.

Read `80_BA-Harness/05_Validation.md`.
Do not silently change stakeholder meaning.
