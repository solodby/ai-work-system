# Раздел Incidents

Здесь фиксируются ошибки, сбои, неудачные решения и неожиданные результаты.

## Обязательная структура

1. Симптом.
2. Воздействие.
3. Временная линия.
4. Доказательства.
5. Причина.
6. Исправление.
7. Проверка.
8. Предотвращение повторения.
9. Открытые вопросы.

## Статусы причин

- `verified` - причина доказана;
- `inferred` - причина наиболее вероятна;
- `open` - причина не установлена.

Не называй workaround окончательным исправлением.
Если решение стало повторяемым, создай связанную заметку в `20_Processes/`.
