# Раздел Decisions

Здесь фиксируются решения, которые влияют на дальнейшую работу.

## Формат решения

- Контекст и проблема.
- Рассмотренные варианты.
- Выбранный вариант.
- Причины выбора.
- Компромиссы.
- Последствия.
- Условия пересмотра.
- Дата и источник.

## Правила

- Фиксируй решение после обсуждения, а не всю переписку.
- Записывай, почему варианты были отклонены.
- Отделяй принятое решение от предложения.
- Если решение изменилось, создай новую запись или явно укажи замену.
- Связывай решение с проектами, процессами и инцидентами.
