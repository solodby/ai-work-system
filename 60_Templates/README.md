# Раздел Templates

Шаблон нужен для ускорения создания заметок, а не для заполнения всех
полей формально.

## Правила шаблонов

- Поля должны помогать искать и проверять информацию.
- Не добавляй поля, которые не используются.
- Сохраняй одинаковые названия полей.
- Не делай шаблон длиннее самой заметки без необходимости.
- После заполнения удаляй подсказки и placeholders.

Шаблоны для основных типов заметок находятся в этой папке.
