# Раздел Processes

Здесь хранятся повторяемые процедуры, по которым можно выполнить работу
или проверить результат.

## Структура процесса

1. Цель.
2. Область применения.
3. Входные данные.
4. Предусловия.
5. Пошаговое выполнение.
6. Варианты и исключения.
7. Риски.
8. Проверка результата.
9. Связанные решения и инциденты.

## Требования

- Шаги должны быть проверяемыми.
- Неизменяемые факты отделяются от ручных действий.
- Ручные действия помечаются `human-execution`.
- Диагностика помечается `read-only`.
- Для опасных действий указывается rollback или recovery.

Процесс считается рабочим только после проверки на реальной или безопасной
тестовой ситуации.
