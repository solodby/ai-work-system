# Requirements

## Required attributes

Each requirement should have:

- unique ID;
- source;
- stakeholder or owner;
- rationale;
- statement;
- priority;
- dependencies;
- acceptance criteria;
- status;
- linked decision and test.

## Quality checks

The requirement should be:

- clear;
- necessary;
- feasible;
- consistent;
- traceable;
- testable.

For a user story, check INVEST:
Independent, Negotiable, Valuable, Estimable, Small, Testable.

## Agent use

The agent may draft, split, rephrase, classify, and find gaps.
The analyst confirms the meaning and the stakeholder approves the requirement.

## Gate G2

Pass when requirements are understandable, linked to a goal, and testable.
