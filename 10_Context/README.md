# Раздел Context

Здесь описываются устойчивые сущности, с которыми ведётся работа:
проекты, продукты, команды, системы, роли, клиенты и ограничения.

## Одна заметка должна содержать

- назначение;
- границы;
- участников;
- входы и выходы;
- зависимости;
- используемые инструменты;
- ограничения;
- связанные процессы и решения;
- источник и дату проверки.

## Не помещать сюда

- разовые задачи;
- необработанные встречи;
- длинные логи;
- секреты;
- неподтверждённые слухи.

## Связи

Связывай контекст с процессами и решениями:

```text
[[Название-Процесса]]
[[Название-Решения]]
[[Название-Инцидента]]
```

Перед задачей агенту обычно достаточно одной context note и связанных
процессов, а не всего раздела.
