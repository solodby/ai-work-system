# Правила системы знаний

## Источники

- У каждой постоянной заметки должен быть источник.
- Дата проверки обязательна для изменяемых фактов.
- Противоречие между источниками фиксируется отдельно.
- Непроверенное утверждение получает статус `open` или `inferred`.

## Структура

- Одна заметка отвечает за одну понятную сущность или тему.
- Имена заметок не меняются без необходимости.
- Связи между заметками оформляются WikiLinks.
- Длинные документы разделяются по смыслу, а не по размеру.

## Работа с ИИ

- Сначала контекст, затем задача.
- Сначала факты и допущения, затем вывод.
- Агент не должен выдумывать отсутствующие данные.
- Важные ответы проверяются по исходным материалам.
- После ошибки сохраняется не только исправление, но и prevention.

## Качество

- Не создавать заметки ради количества.
- Не дублировать одну информацию в нескольких местах без ссылки на источник.
- Удалять устаревшие инструкции или явно помечать их как устаревшие.
- Каждая процедура должна иметь проверку результата.

## Конфиденциальность

- Не хранить пароли, токены, ключи и секретные файлы.
- Обезличивать персональные и коммерческие данные.
- Не передавать внешней модели данные без проверки политики доступа.
